# Dynamo

Đặt tên file: `ARV_<Chức năng>_v<Số>.dyn`. Gom node thành nhóm có tiêu đề tiếng Việt. Python node ghi comment input/output ở đầu.

**Core Console gọi từ Revit (sửa 2026-10-19):** tiến trình con kế thừa `Path` có thư mục Revit 2026 → `accoreconsole.exe` nạp nhầm DLL, báo "Unable to load the Modeler DLLs" và thoát → node báo "Core Console không xuất được dữ liệu…". Các tool đọc DWG (`TaoSanHoanThien`, `TaoSanCanHoTuCAD`, `TaoDamTuCAD`, `TaoTrucTuCSV`, `VeBaoSanTuCAD`) giờ gọi Core Console bằng hàm `core_env()` (môi trường sạch, `Path` = thư mục AutoCAD + Windows, cwd = thư mục AutoCAD). Đã kiểm trong tiến trình Revit qua MCP: môi trường gốc → lỗi Modeler; môi trường sạch → chạy được. Bản trước: `99_BACKUP\2026-10-19_dynamo-truoc-sua-core-console.zip`.

### ARV_TaoCotVachTuCAD_v1 – cách chạy
1. Mở file local/copy của mô hình Kết cấu, Link bản DWG (đơn vị millimeter) vào đúng vị trí.
2. Manage → Dynamo → mở `ARV_TaoCotVachTuCAD_v1.dyn` (chế độ chạy Manual).
3. Family cột: dùng `M_Concrete-Rectangular-Column` (Insert → Load Autodesk Family, parameter `b`, `h`). Nếu mô hình chưa có, script tự load từ file ở IN[10] (mặc định `tools/dynamo/families/M_Concrete-Rectangular-Column.rfa`; lưu file này từ Revit: chọn family → Edit Family → Save As). IN[3] để trống thì lấy tên family theo tên file. Dry-run load tạm rồi hoàn tác.
   Điền IN[6] wall type mẫu, IN[7]/IN[8] level chân/đỉnh. Ô sai hoặc trống → node "Báo cáo" liệt kê giá trị hợp lệ.
4. IN[1] lọc layer theo chuỗi con, mặc định `$0$S-Cot vach` (lấy layer cột vách trong block mặt bằng, gồm cả `S-Cot vach dung`, không lấy layer chi tiết vách ở model space).
5. Giữ **Dry-run = True**, bấm Run, đọc "Báo cáo" và log trong `Documents\ARV_Logs`. Đúng thì đổi Dry-run = False và Run lại. Undo bằng mục "ARV - Tạo cột vách kết cấu từ CAD".

### ARV_TaoDamTuCAD_v1 – cách chạy
1. Mở file local/copy của mô hình Kết cấu, **Link** (không Import) bản DWG mặt bằng kết cấu sàn (đơn vị mm) vào đúng vị trí. File DWG phải còn ở đường dẫn gốc; máy cần AutoCAD Core Console (`C:\Program Files\Autodesk\AutoCAD *\accoreconsole.exe`). Nhãn được đọc cả ở model space lẫn **trong block** (lồng nhau tới 8 cấp, đổi toạ độ/góc chữ theo điểm chèn, tỉ lệ, góc xoay của block; chữ trên layer `0` trong block lấy layer của block).
2. Manage → Dynamo → mở `ARV_TaoDamTuCAD_v1.dyn` (chế độ chạy Manual).
3. Đầu vào:
   - IN[1] layer cạnh dầm, mặc định `S-Khuat;S-Thay` (nét khuất dầm + mép sàn, vì dầm biên lấy mép sàn làm một cạnh).
   - IN[2] layer nhãn, mặc định `S-Text`; IN[3] hệ số đổi nhãn ra mm: nhãn ghi cm (`25X40`) → 10, ghi mm (`250x400`) → 1. Nhãn có tiền tố (`D1 (22x50)`) vẫn đọc được.
   - IN[4]–IN[6] family dầm + parameter `b`, `h` (mặc định `M_Concrete-Rectangular Beam`). Chưa có type đúng b × h thì tự tạo type `{b} x {h}mm`.
   - IN[7] level tham chiếu, IN[8] đỉnh dầm so với level (mm). Dầm đặt Y-justification = Center, Z-justification = Top.
4. Cách nhận dầm: mỗi nhãn `bxh` → tìm cặp nét song song với chữ, cách nhau đúng b (±15 mm), sát nhãn (≤ 800 mm) → trục dầm là đường giữa. Chiều dài = đoạn hai cạnh cùng có nét (nối qua chỗ một cạnh bị dầm khác đâm vào, ≤ 2000 mm). Đầu dầm chạm mép dầm vuông góc → kéo tới trục dầm đó. Hai nhãn khác tiết diện trên cùng một trục → cắt tại trục dầm cắt ngang rộng nhất (dầm chính làm gối) nằm giữa hai nhãn.
5. **Dầm liên tục ghi 1 nhãn** (IN[10], mặc định 2500 mm): các nhịp thẳng hàng của cùng cặp nét (cùng bề rộng), cách nhau qua cột / vách / nút dầm chữ thập ≤ IN[10], được tạo theo nhãn đó, mỗi nhịp một dầm (dừng ở mép cột), tới nhịp có nhãn khác thì thôi. Nhịp nằm giữa hai nhãn → theo nhãn gần hơn (đếm số nhịp); cách đều hai nhãn khác tiết diện → báo "kiểm tra lại". Báo cáo ghi "nhịp nối theo nhãn". IN[10] = 0 → chỉ tạo nhịp có nhãn.
   **Giới hạn:** dầm cong chưa hỗ trợ; dầm dừng ở mép cột/vách, Revit tự nối.
6. Giữ **Dry-run = True**, bấm Run, đọc "Báo cáo" và log trong `Documents\ARV_Logs`. Đúng thì đổi Dry-run = False và Run lại. Undo bằng mục "ARV - Tạo dầm kết cấu từ CAD".
   Chạy lại trên level đã có dầm: dầm mới cùng trục và chồng > 50% chiều dài với dầm cũ → bỏ qua ("đã có dầm cùng trục" + Id dầm cũ), chỉ tạo dầm còn thiếu; dầm cũ không bị sửa.
7. Đã chạy thử phần nhận dầm (ngoài Revit) với `mbkc t2.dwg`: 62/62 nhãn (33 ở model space + 29 trong block `dam bo hkt N`) → 62 dầm (IN[10] = 0) / 66 dầm (IN[10] = 2500). Mô phỏng chạy lại trên mô hình đã có 35 dầm: 35 bỏ qua, 31 tạo mới. Ảnh soát `ARV_TaoDamTuCAD_v1_soat-tang2.png`.

### ARV_VeBaoSanTuCAD_v1 – cách chạy
1. Mở file local/copy của mô hình Kết cấu, **Link** (không Import) bản DWG mặt bằng kết cấu sàn (đơn vị mm) vào đúng vị trí. File DWG phải còn ở đường dẫn gốc; máy cần AutoCAD Core Console. **Mở view mặt bằng của tầng cần vẽ** (đường bao vẽ trong view đang mở; sàn tạo trên level của view).
2. Manage → Dynamo → mở `ARV_VeBaoSanTuCAD_v1.dyn` (chế độ chạy Manual).
3. Đầu vào:
   - IN[1] layer mép sàn, mặc định `S-Thay;S-Cot vach` (mép sàn / mép ngoài dầm biên, mép lỗ mở + vách lõi khép kín mép sàn).
   - IN[2] layer dấu lỗ mở, mặc định `S-Manh`: ô kín nhỏ nhất chứa dấu X (2 nét chéo cắt nhau tại trung điểm) là lỗ mở.
   - IN[3] layer hatch, mặc định `S-Hatch`. IN[4] ghi chú hatch `MẪU=dày[/cốt]` (mm, cốt âm = hạ cốt), mặc định theo bảng ghi chú sàn `ANSI31=230;STARS=250;TRIANG=500;ANSI37=450/-50`. Hatch có mẫu không nằm trong IN[4] (VD `CHAU-01` của cột) bị bỏ qua, báo trong báo cáo.

3. **Mạch lát sàn** (Revit không cho đọc / dời gốc mẫu qua API – đo bằng ảnh xuất view trên G19 2026-10-21, khớp 9/9 tấm): trục 0° của Model pattern song song **cạnh dài nhất** của biên sàn, mạch đi qua **tâm hộp bao** biên sàn. Với `300x600` (lưới 0° cách 300, lưới 90° cách 600): mạch cách 600 dọc cạnh dài nhất, 300 theo phương kia. Tấm sàn đã Align mẫu bằng tay → tool không biết; hai cạnh dài nhất bằng nhau mà vuông góc → báo "không chắc hướng mẫu".
4. Mỗi đoạn len (tìm như `ARV_TaoLenGo_v1`: tia 60 mm tới mặt tường / cột / gờ, ngắt tại cửa, góc gặp nhau tại giao tim) được chia tại mạch sàn cắt ngang → mỗi viên một Basic Wall, không nối đầu (thấy mạch ở 3D / mặt đứng). Viên vụn < IN[5] ở đầu đoạn gộp vào viên kề. Comments `ARV-LenGachLogia <Id sàn>`; sàn đã có len của tool → bỏ qua (xoá để làm lại).
5. Giữ **Dry-run = True**, Run, đọc "Báo cáo" + log `Documents\ARV_Logs\TaoLenGachLogia_*.csv`. Đúng thì Dry-run = False, Run lại. Undo bằng mục "ARV - Tạo len gạch logia".
6. Đã thử 2026-10-21 trên G19 (Tầng 1, 27 sàn logia): phần chia viên chạy ngoài Revit với biên sàn thật (giả định mọi cạnh có tường) → 632 viên, 40 viên vụn gộp, 0 viên < 20 mm; vẽ mạch len dự kiến đè lên mẫu sàn trong Revit (MCP, hoàn tác) – 3/3 tấm soát (CH02, CH05, CH10) trùng mọi mạch. **Chưa chạy `.dyn` trong Dynamo** (phần dò tường / cửa / Wall.Create dùng lại nguyên của `ARV_TaoLenGo_v1`).

### ARV_TaoThietBiWCTuCAD_v1 – cách chạy
1. Mở **bản sao** / file local của mô hình đã có tường + lớp ốp WC (`ARV_OpTuongWC_v1`) + **sàn WC** (`ARV_TaoSanCanHoTuCAD_v1`, Comments chứa `WC`); bản DWG mặt bằng vẫn **Link** đúng vị trí (view-specific trên mặt bằng của tầng – level lấy theo view đó). Load sẵn family `AV-Toilet` và `AV-Bàn Lavabo chữ nhật bán âm` (template công ty).
2. Manage → Dynamo → mở `ARV_TaoThietBiWCTuCAD_v1.dyn` (Manual) → Run.
3. Đầu vào (KTS chốt 2026-10-21 cho G19: chỉ bệt + lavabo, lavabo bán âm nhân bản type theo CAD, chân = mặt sàn WC −15, WC chưa có sàn vẫn đặt):
   - IN[0] tên bản CAD (trống = bản CAD link duy nhất có layer IN[1]). IN[1] layer lavabo `A-Interior WC`, IN[2] layer bệt `0` (khớp đúng tên).
   - IN[3] bệt `AV-Toilet : AV-Toilet` (một type cho mọi WC). IN[4] family lavabo, IN[5] type mẫu `900x470` (phải có tham số `Width`, `Depth`).
   - IN[6] cao độ chân khi thiết bị **không** nằm trên sàn WC nào (mặc định −15). IN[7] tầm dò mặt tường hoàn thiện sau lưng CAD (100 mm; 0 = giữ đúng toạ độ CAD). IN[8] Dry-run.
4. Cách nhận trên CAD (đọc hình học link trong Revit – block động hiện theo trạng thái hiển thị):
   - **Lavabo** = polyline chữ nhật kín layer IN[1], cạnh dài 800–1100, ngắn 400–650 (khung ngoài block 半挂式台盆); khung lồng trong khung lớn hơn bỏ. Lưng = cạnh dài phía vòi (trọng tâm nét trong khung lệch về phía vòi ~125 mm). Type `{rộng}x{sâu}` làm tròn 10 mm; chưa có → nhân bản IN[5], đặt `Width`/`Depth` (tên trùng type khác kích thước → thêm ` (ARV)`).
   - **Bệt** = cung R 150–230, quét 160–190° (đầu bệt) + nét két nước vuông góc trục, dài 1,6–2,5R, lệch trục ≤ 60 mm, sau cung 1,8–3,5R; tổng sâu 600–800 mm. Cung không có két (G19: 24 cung R200 cạnh lõi thang) → bỏ, liệt kê trong báo cáo.
5. Cách đặt: tia dò ở +300 mm từ trước lưng 150 mm ra sau lưng IN[7] mm (3 tia dọc lưng) → lưng áp mặt tường / cột / ốp gần nhất; không gặp → giữ CAD. Lavabo: tia ngang ở +700 hai bên – lấn mặt hoàn thiện tường bên ≤ 50 mm và bên kia đủ chỗ → dời ngang ra (giữ kích thước CAD); lấn hơn hoặc kẹp hai bên → giữ CAD, báo **KIỂM TRA**. Lưng / giữa thân đo trên khối đặc family sau khi đặt (bệt: lưng két; lavabo: mặt gương / mặt đá phía tường). Bệt (Work Plane) **host lên mặt trên sàn WC** (Schedule Level = level); lavabo (theo level) Offset from Host = cao độ sàn WC. Không có sàn WC → bệt nằm trên level (Work Plane, không hạ được), lavabo Offset = IN[6]. Comments `ARV-ThietBiWC BET|LAVABO CHxx`. Đã có thiết bị cùng family tại chỗ (khối đặc chứa điểm trước lưng CAD 100 mm) → bỏ qua.
6. Giữ **Dry-run = True**, Run, đọc "Báo cáo" (OUT[1]: khung thiết bị theo CAD) + log `Documents\ARV_Logs\TaoThietBiWCTuCAD_*.csv`. Đúng thì Dry-run = False, Run lại. Undo bằng mục "ARV - Tạo thiết bị vệ sinh WC từ CAD".
7. Đã thử 2026-10-21 trên `G19.rvt` (CAD `G19.dwg`, Tầng 1) bằng bản C# tương đương qua MCP (rồi hoàn tác): **32 bệt + 32 lavabo** (900×500 ×24, 1000×500 ×6, 1000×550 ×2 → nhân bản 3 type), 64/64 đúng hướng, lưng trùng mặt hoàn thiện (±1 mm), dời áp tường 10–25 mm (2 cái −65 / −75: CAD cách tường), 27 lavabo dời ngang 15–25 mm; **63/64 không giao tường**. Còn: lavabo CH02 (lưng 26240, 18200) lấn tường bên 125 mm → giữ CAD, báo KIỂM TRA; WC CH04 x ≈ 48875–49575, y ≈ 28650–30290 chưa có sàn → bệt nằm ở ±0. Hàm nhận dạng thử ngoài Revit.
8. **Lần chạy Dynamo đầu (2026-10-21, người dùng):** 32 bệt đúng (31 host lên sàn WC, đáy −15; CH04 ở ±0), nhưng 26/32 lavabo **không xoay** – nằm quay +Y, lưng không áp tường, Comments trống – do CPython3 không cộng `XYZ + XYZ` (lỗi `unsupported operand type(s) for +: 'XYZ' and 'XYZ'` ở `RotateElement`) và phần tử đặt dở không được hoàn tác. Đã sửa: `XYZ.Add`, mỗi thiết bị một SubTransaction, thiết bị cùng family phủ ≥ 30 % khung CAD mà **sai hướng** → xoá + đặt lại (dry-run báo "Sai hướng (Id …) → sẽ xoá + đặt lại"). Chạy lại tool là sửa được 26 lavabo; 6 lavabo đúng + 32 bệt giữ nguyên.
